# UAllera

Software locale per controllare esercitazioni jamovi e relazioni Word raccolte in uno ZIP con cartelle degli studenti.

Il progetto è in sviluppo. I test automatici distinguono presenza degli output, correttezza numerica verificabile e aspetti che richiedono la valutazione del tutor. Il rapporto è unico, con una sezione per studente.

Il software funziona sul PC senza servizi esterni. Le distribuzioni previste sono Windows x64 e Windows ARM64.

Questa repository contiene codice e test artificiali. Non contiene consegne reali degli studenti né la soluzione completa dell’attività in corso.
